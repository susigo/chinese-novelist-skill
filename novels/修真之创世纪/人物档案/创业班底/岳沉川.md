# 岳沉川

- **年龄/职业**：初登场二十八岁左右；边荒刀修 / 护路人，后为主角阵营战斗支柱之一
- **外貌特征**：身形高大，眉骨冷硬，左肩留有旧伤，话少，站在人群里像块压着风雪的铁石
- **性格核心**：沉默坚忍、重诺守界、极有战场直觉，看似冷硬，实则把“自己人”看得极重
- **核心价值观**：人活着总得守住点什么；若连身后之人都护不住，再强的刀也只是空壳
- **最大恐惧**：再一次眼睁睁看着同伴和无辜者死在强者余波之下，却什么都做不了
- **致命缺陷**：习惯以硬碰硬解决问题，前期不善表达，也不擅长相信那些看起来太“聪明”的计划
- **内心渴望**：想找到一个值得自己真正赌命去守的人和路，不再只是为佣金、为活命挥刀
- **背景故事**：曾在边荒护商、守矿、押路，也做过散修雇佣战修，见惯了宗门、世家与匪修之间把底层修士和凡人当消耗品的做法。数次死里逃生后，他对所谓大人物和大势从不抱幻想。最初与林渊相识时，也只是把他当一个迟早会死在边荒的聪明人，直到后来亲眼看到林渊如何在弱小时就试图护住身边人。
- **MBTI**：ISTJ
- **人物定位**：战斗型伙伴 / 前期护道者 / 后期军主或星君种子
- **人物功能**：
  - 承担前期最直接的战斗压力与护持职责
  - 作为主角阵营最早的“武力信任”来源之一
  - 代表那些并不擅长讲道理、却愿意用命去证明道路的人
- **与主角关系演变**：
  1. 先以雇佣、合作、互救关系接触
  2. 在一次次共战中，从不信任主角到愿意为其断后
  3. 后期成长为军主、一方星君或边域镇守核心人物
- **成长方向**：
  - 前期：边荒雇战修
  - 中期：主角阵营核心战将
  - 后期：星域军主 / 镇守型星君候选
- **高光方向**：
  - 在主角最脆弱阶段多次硬生生扛住外部杀局
  - 作为最朴素、最不讲虚言的人，反而最能证明主角这条路值得拿命去押
  - 中后期当主角秩序扩张时，他是“秩序也需要被守住”这一点最具体的体现
