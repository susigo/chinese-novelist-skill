# 苏半夏

- **年龄/职业**：初登场二十四岁左右；坊市药铺出身，兼做账房、采买与小规模商路经营
- **外貌特征**：眉眼清利，着装素净利落，说话不快，却总能一针见血点到价格、成本与人心要害
- **性格核心**：冷静务实、极擅算账，外柔内硬，对资源流动和风险判断极其敏锐
- **核心价值观**：再宏大的理想，若不能落到账本、货路和供给上，就只是空话
- **最大恐惧**：好不容易建立起来的秩序因为供给断裂、资源失衡而崩塌；也害怕自己再度沦为被大势随意吞掉的小人物
- **致命缺陷**：过于看重投入产出，前期容易对“看不见回报的理想”保持怀疑；不轻易相信口号
- **内心渴望**：想建立一种不靠依附豪门、不靠讨好宗门也能稳稳运转的资源网络
- **背景故事**：出身坊市小商之家，自幼跟着家里经营药材、符纸、低阶灵物买卖，对底层修士最真实的消费与生存逻辑极熟。家业曾因世家压价、宗门抽成和黑市盘剥几近崩塌，因此比常人更懂垄断的可怕。她最初接触林渊，是因为发现这人不仅会改东西，还真的在想如何让资源流转更公平。
- **MBTI**：ESTJ
- **人物定位**：商路型人物 / 资源调配者 / 主角阵营经济线起点
- **人物功能**：
  - 负责坊市经营、资源采购、成本测算、收益模型建立
  - 为主角的技术成果找到真正落地与流通的路径
  - 把“数字修真”从个人能力逐步转化为可持续的供给体系
- **与主角关系演变**：
  1. 先把林渊当成有潜力的技术散修合作对象
  2. 发现林渊不仅能造东西，还想重构交易秩序后开始真正投入
  3. 后期成长为商盟或资源调配体系的关键负责人
- **成长方向**：
  - 前期：坊市经营者与账路管理者
  - 中期：跨区域资源网络组织者
  - 后期：商盟中枢 / 天庭资源调配负责人候选
- **高光方向**：
  - 在主角最缺资源时，帮他把“技术”变成第一桶金
  - 用账本、货路和供给证明主角路线不仅能打，还能养活人、养活体系
  - 在经济线冲突中，是最能体现“新秩序如何落地”的关键人物
