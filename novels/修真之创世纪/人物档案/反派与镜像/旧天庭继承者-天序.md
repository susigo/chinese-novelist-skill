# 天序

- **年龄/职业**：实际年龄远低于旧天庭覆灭年代，初登场年龄成谜，外貌如三十岁许；御天神宫最后一位神君的继承者之一
- **外貌特征**：气度森严，衣冠古制，目光像能穿透一个人的前世今生；身上总有一种“他不是个人，而是一段秩序仍在说话”的压迫感
- **性格核心**：克制、肃正、冷酷而有责任感，不沉溺私欲，甚至可以说比许多正派人物更像真正的“执政者”
- **核心价值观**：秩序必须高于众生意愿，天下之所以痛苦，不是因为秩序太强，而是因为秩序不够强、不够统一、不够不可违逆
- **最大恐惧**：林渊重建出的新天庭会因为过度考虑众生、开放上升通道和允许变化，而重复旧时代崩塌前的软弱与失控
- **致命缺陷**：太相信绝对秩序，最终将众生视为秩序的承载材料而非秩序的目的；他的公正极强，却缺少温度
- **内心渴望**：完成御天神宫未竟之业，证明只有彻底统一、彻底审定、彻底服从的天庭，才有资格统御诸天
- **背景故事**：天序与旧天庭残序、遗迹与意志深度绑定，是某种意义上被过去选中的人。他所继承的旧天庭，真正名称是“御天神宫”——一个由多方顶级势力共同维系的松散联盟秩序，核心靠中央神宫与地方天王体系共治诸域。天序并非与最后一位神君同时代的人物，两者之间隔了约五千年，但他是那位最后神君留下的继承者之一。更准确地说，他是从后续延续下来的神君候选血脉中被筛选出来的“少主”之一，需要通过神族功法试炼、统治试炼与遗迹试炼，才能一步步接近真正的神君继承权。他所继承的是被拆散封入后世的法统、权限、记忆与旧秩序机制，而不是某个五千年寿元未尽的活人身份。正因如此，他既继承了御天神宫的大量法统、结构、审定逻辑与失败记忆，也继承了一份“重构秩序”的未竟使命。
- **MBTI**：ISTJ
- **人物定位**：旧秩序继承者 / 神君遗产继承者之一 / 主角在“谁更有资格重构秩序”问题上的终极镜像
- **人物功能**：
  - 让后期冲突不只是“要不要建天庭”，而是“谁更有资格、用什么方式重建天庭”
  - 代表御天神宫的合法性、经验、教训与阴影
  - 把主角最终敌人提升到“并非反对秩序重构，而是主张另一种更冷、更强、更绝对的重构方式”
  - 通过他，揭示旧天庭失败并非只因外敌或衰败，更因中央神宫与地方天王体系之间的结构性冲突
- **与主角冲突**：
  - 林渊认为天庭应服务众生、约束强者、维持平衡
  - 天序认为天庭必须凌驾众生、审定一切、禁止变化，先完成统一，再谈其他
  - 两人都在朝着“重构秩序”的方向努力，但一个要建立服务未来的开放新秩序，一个要继承并强化旧天庭的统御逻辑
  - 中期阶段，天序更倾向于依托旧遗迹、旧资源与现成技术夯实自身势力根基，形成稳固扩张
  - 林渊则更偏向抢夺关键资源，并用新技术快速迭代武器、法器和体系能力，从而实现以少胜多、以弱胜强
  - 天序比一般反派更危险，因为他不是空谈理想，而是真有足够资源和积累去与主角竞争天下
- **资源与竞争优势**：
  - 掌握御天神宫遗留的大量宝藏、秘库与传承线索
  - 能优先开启或利用未知旧时代资源遗迹
  - 拥有部分失落星门、古航道和残缺通行网络的控制权或坐标
  - 可调用旧天庭残序、古制权柄、隐藏势力与沉睡资源
  - 作为少主竞争中的领先者，他在中期便已提前获取神君体系中的部分实际权力
  - 这意味着他不是“有资格的人”，而是已经能部分动用神君秘密力量的人
  - 他最强的地方之一，在于能把“旧遗产 + 现成体系 + 既有资源”迅速转化为稳固势力
  - 因为起点更高、积累更深，所以他是主角在中后期最强力也最合理的秩序竞争者之一
- **能力方向**：
  - 极强的规则审定、秩序压制与旧天庭法统调动能力
  - 擅长借助旧遗迹、残序网络、古制权柄对天地施加影响
  - 兼具统御、资源整合与文明级遗产利用能力
  - 是那种越接近终局越恐怖的统御型敌手
- **成长方向**：
  - 前期：以影子、遗迹、意志片段、代行者和资源线索形式埋线；同时在暗线中与其他少主竞争继承资格
  - 中期：凭借能力提前获取神君体系中的实际权力，压过其他少主，开始真正调动秘库、星门与秘密力量，并与主角争夺遗迹、资源和旧秩序解释权
  - 后期：完成从“少主领先者”到“旧秩序实际掌权竞争者”的转变，成为主角在“新天庭为何而立、如何而立”问题上的最终审判者与竞争对手
- **高光方向**：
  - 他不应像暴君，而应像一个真正有能力、有准备、有资源去重建秩序的人
  - 让读者清楚感受到：如果林渊是白手起家的新世界开创者，天序就是站在旧文明遗产之上的正统继承者
  - 他拥有宝藏、遗迹、星门、法统和横跨五千年传承下来的隐秘优势，因此他的威胁不只是强，而是“先发于时代”
  - 他的崛起不是天命掉下来，而是踩着少主竞争、试炼筛选与提前掌权一步步打出来的
  - 最终主角必须不是单纯打败他，而是证明“秩序不该高于众生存在本身”，也证明新秩序并不必然输给旧文明遗产的厚重积累
