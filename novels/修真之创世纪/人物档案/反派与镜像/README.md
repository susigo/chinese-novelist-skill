# 反派与镜像人物索引

这些角色不是单纯意义上的“坏人”，而是主角在不同维度上的镜像对手，分别代表另一种可能的未来。

## 已建立角色
- `人物档案/反派与镜像/血脉派第一天骄-澹台烬.md`
  - 代表：血统秩序、强者天生论
- `人物档案/反派与镜像/古法派悟道怪物-宁观玄.md`
  - 代表：大道不可言传、不可量化
- `人物档案/反派与镜像/器道联盟首席-公输野.md`
  - 代表：技术垄断、封闭工业化修真
- `人物档案/反派与镜像/旧天庭继承者-天序.md`
  - 代表：绝对统御主义、御天神宫合法性与神君遗产继承权

## 使用原则
- 这四人都应具备独立逻辑与人格尊严，不能写成脸谱化反派。
- 他们不是只负责给主角送经验，而是负责逼主角回答四个终极问题：
  1. 众生是否真的可塑？
  2. 大道是否真的可被公共化？
  3. 技术应当开放还是被垄断？
  4. 天庭到底应服务众生，还是凌驾众生？
