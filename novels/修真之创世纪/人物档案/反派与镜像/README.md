## 使用原则
- 这些镜像对手都应具备独立逻辑与人格尊严，不能写成脸谱化反派。
- 他们不是只负责给主角送经验，而是负责逼主角回答四个终极问题：
  1. 众生是否真的可塑？
  2. 大道是否真的可被公共化？
  3. 技术应当开放还是被垄断？
  4. 天庭到底应服务众生，还是凌驾众生？
