# 沈策

- **年龄/职业**：初登场二十三岁左右；凡人出身，后成为主角阵营的首席谋主与制度设计者
- **外貌特征**：身形清瘦，面容温雅，常着素色长衫，不带任何修士锋芒；中后期会逐渐出现鬓发霜白、病容加深的变化
- **性格核心**：克制沉稳、擅观大势、极懂人心，善于在复杂利益之间找到可落地的平衡解
- **核心价值观**：秩序若不能护住普通人，再辉煌的大道也只是强者的玩物
- **最大恐惧**：主角最终赢了天下，却失了“人间”；新秩序若只是旧秩序换了名字，那一切牺牲都没有意义
- **致命缺陷**：太能忍、太能扛，明知自己只是凡人却总习惯以有限寿命去硬撑无限大局；往往不在乎自己的身体与结局
- **内心渴望**：想亲眼看见一个普通人不再被随意碾压、凡人也能被制度真正保护的时代到来
- **背景故事**：出身凡俗书吏之家，少时见过王朝、世家、宗门对凡人命运的层层压榨，因此比任何修士都更敏锐地理解“秩序”对人间的重要性。他本人没有灵根，也无修行机缘，却以惊人的结构思维、治理能力和谋局天赋，在边荒与乱世之中一步步成为主角最重要的智囊与制度共创者。以他的出身与体质，原本寿数大致只在凡人常规范围；即便后期享受顶级医药、灵药温养与丹府照护，也只是把寿数尽量稳到百岁上下、极限拖到百余岁，代价高昂且无法复制，更不可能把他直接抹平成拥有修士寿元的人。
- **MBTI**：INFJ
- **人物定位**：凡人谋主 / 治世家 / 人间锚点 / 天庭制度原型共同设计者
- **人物功能**：
  - 为主角补足政治、治理、用人、分配、制度设计能力
  - 持续提醒主角“秩序首先要保护凡人”
  - 让主角阵营拥有真正意义上的人间视角
  - 作为主角从“重构规则”走向“隔离三界、补全死后秩序”的关键思想触发者
  - 作为长篇情感高潮的核心承载角色之一
- **与主角关系演变**：
  1. **互相利用阶段**：他看中林渊身上的时代潜力，林渊看中他的布局与判断能力
  2. **真正信任阶段**：经历数次生死与大局危机后，形成“林渊定道，沈策定局”的核心默契
  3. **理想共同体阶段**：不再只是主从或谋士关系，而是新秩序最早的共同设计者之一
- **核心冲突**：
  - 身为凡人，却参与制定未来的仙道秩序，因此常遭高阶修士轻蔑与敌视
  - 当林渊越来越强、寿元越来越长时，他却不可逆转地衰老、逼近死亡
  - 在世界尚未分出三界之前，他始终亲眼见证凡人如何被修士战争与高阶力量余波反复碾压
  - 林渊明明能改变天下格局，却未必能留住一个凡人的一生
- **高光方向**：
  - 设计人界治理框架、星君分区原则、凡修流转制度、资源分配底层逻辑
  - 在关键大战之外，凭借政治布局与人心判断为主角争取最珍贵的时间和空间
  - 多次指出主角方案中的“技术正确但人间失衡”问题，成为其文明道路的重要校准者
  - 其离世过程将直接暴露旧时代“死后无序”的残酷现实，成为冥界构想的重要源头之一
- **结局预设**：
  - 不建议让其简单病逝，而应作为长线悲剧角色处理
  - 推荐方向：林渊后期有能力为其逆天续命或塑造修行根基，但沈策主动拒绝
  - 他的理由不是自轻，而是他清楚自己之所以重要，恰恰因为他始终是个凡人
  - 在旧世界规则下，沈策死后本应像绝大多数凡人一样魂归茫茫宇宙、迅速散去
  - 林渊会在其离世时尝试以尚未成熟的手段保住其一缕完整魂印或命识，这一尝试将成为“灵魂维持体系”的起点之一
  - 因此，沈策之死不只推动林渊意识到必须切割高阶修士与人间，也直接推动他补全“死者归处”这一世界缺环
  - 他将成为“隔离三界”与“开辟冥界”两大构想正式成形的共同转折点
- **遗产设定**：
  - 新天庭关于三界划分的底层理念，部分源于沈策长期坚持的人间视角
  - 冥界最初建立的价值诉求之一，也源于林渊不愿再让凡人死后无声无息散入宇宙
  - 天庭核心律令中至少有一条直接出自沈策理念
  - 可设为：**“天庭立于诸天之上，不得忘其根在人界。”**
  - 其死后并不只以回忆存在，而是以制度、架构和主角决策逻辑延续其影响
