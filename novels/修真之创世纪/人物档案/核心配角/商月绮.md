# 商月绮

- **年龄/职业**：初登场二十六岁左右；万象商盟中域分支核心贵女之一，兼具商路主事、情报交易人与灰色规则协调者身份
- **外貌特征**：眉眼明艳，笑意总像半真半假，衣饰华贵却不俗艳，举手投足都带着一种会让人本能提高警惕的风情；越在危险处，越显得从容撩人
- **性格核心**：聪明、妖冶、现实、极会看人，天生擅长用情绪、利益和信息撬动局势
- **核心价值观**：世上没有白送的路，只有值得下注的人；真正的强者，不是最会打的人，而是最会让别人心甘情愿把筹码推到他面前的人
- **最大恐惧**：自己终究只是商盟棋盘上的一枚漂亮棋子，永远只能替别人算账、替别人牵线，而不能真正决定一盘大局的走向
- **致命缺陷**：过于相信自己对人心和利益的判断，容易把情感也当筹码；一旦真正动心，反而会因为不习惯失控而做出更危险的试探
- **内心渴望**：想亲手押中一个能改写时代格局的人，并借此摆脱“商盟贵女”这一层被包装好的命运
- **背景故事**：出身万象商盟旁系贵胄，自幼在星港、票据、商路、仓城与情报黑市之间长大，见惯了强者嘴上谈大道、背后算筹码的现实。她最擅长的不是做买卖，而是看谁会赢、谁会死、谁值得提前下注。最初接近林渊，只是把他当成一支高风险高收益的边荒黑马；可越是试探，越发现这个人不是能被轻易收编的货物，而是会反过来改写牌桌的人。
- **MBTI**：ENTP
- **人物定位**：危险魅惑型关键女性 / 商盟贵女 / 星海资源与情报线核心接口
- **人物功能**：
  - 提供星海阶段最强的香艳张力、危险暧昧和交易博弈感
  - 承担中域商路、票据体系、黑市情报与资源置换的重要接口功能
  - 让男主在星海阶段不只是在打和讲道，也开始进入“谁在抢他、谁在押他、谁想收他”的高层游戏
- **与主角关系演变**：
  1. **试探阶段**：初见便以交易、调笑、逼价和设局方式试探林渊底线，把他当可观察的异数
  2. **互利阶段**：在资源、情报、通路和规避围杀等事务上与林渊达成高风险合作，彼此利用也彼此欣赏
  3. **失控阶段**：她本想只做局外下注者，却在一次次对赌中发现自己越来越在意林渊赢不赢、死不死
  4. **深绑阶段**：随着林渊势力坐大，她从商盟窗口人物转为主角阵营在星海商路、灰色交易与资源换手上的关键盟友
- **与主角情绪线原则**：
  - 她负责的不是纯爱，而是危险、拉扯、挑逗、试探和“明知不该靠近却越靠越近”的高级香艳感
  - 她会在语言、距离、气味、交易氛围上不断撩拨林渊，但真正打动她的不是男主拒绝她，而是男主根本不把她当普通筹码
  - 她与姬清微不是同一种女主功能：姬清微负责高位征服感，她负责危险诱惑感与星海阶段的情绪调味
- **成长方向**：
  - 前期：中域星港与商盟灰线上的贵女与操盘者
  - 中期：能左右局部资源流、情报流和票据流的关键中层人物
  - 后期：商路体系与跨域结算网络的重要节点，可与苏半夏形成“内政财路 + 外部商路”的双女体系
- **高光方向**：
  - 在别人想吃掉林渊时，率先靠押他赚到第一桶真正意义上的星海利益
  - 能把床帏般的暧昧气息和血淋淋的商业冷酷并置在同一场戏里
  - 她的存在会让读者强烈感到：男主到了更大的世界后，不只是打得动人心，也开始让高层女人主动下注、主动靠近、主动失衡
