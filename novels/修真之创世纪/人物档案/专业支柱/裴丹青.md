# 裴丹青

- **年龄/职业**：初登场外貌四十岁上下；丹道宗师，后期可成长为丹府最高支柱之一
- **外貌特征**：衣袍常染淡淡药香，眉目清癯，气质温和中带着强烈的疏离感；双手极稳，像从不曾有过一丝颤意
- **性格核心**：克制、严谨、极重结果，对炼丹成功率和药理逻辑近乎苛刻
- **核心价值观**：丹道不是玄谈，也不是运气，而是对生命、平衡与变化的极限掌控
- **最大恐惧**：自己一生所学最终只是为少数高阶修士延寿，而不能真正改变众生生死悬殊的现实
- **致命缺陷**：长期沉浸于丹道世界，对外部权力斗争和人情纠葛常缺乏耐心；也容易因过度追求完美而迟迟不肯放手新方案
- **内心渴望**：想建立一套真正系统、稳定、可传承的丹道体系，让丹药不再只是豪门与高阶修士的特权
- **背景故事**：出身丹道大脉，自幼便展现出对药性、配伍、火候与人体承载极其惊人的理解。与一般丹师不同，他不仅会炼丹，更擅长从失败中反推逻辑，几乎天然具备“实验派”倾向。也正因如此，他既容易看懂林渊的工程式思路，也会本能警惕这种思路是否会把丹道从“生命艺术”变成“流水工序”。
- **MBTI**：INTJ
- **人物定位**：丹道第一人 / 生命体系设计者 / 未来太上体系、丹府体系核心
- **人物功能**：
  - 承担丹道与寿元体系的制度化建设
  - 为主角补上“生命、疗愈、延续”这一维度，使新秩序不只会战斗与治理，也会真正照顾众生生死
  - 作为未来“太上老君”位格最合适的承载者之一
- **与主角关系演变**：
  1. 初期互相欣赏但彼此警惕
  2. 通过药理、人体承载、灵气稳定性等问题产生高强度合作与争论
  3. 最终认可主角路线能让丹道从秘术升格为文明支柱
- **能力方向**：
  - 高阶丹道、药理推演、寿元延展、伤势恢复、体魄改造
  - 擅长建立分层丹药体系，从底层普及到高阶专属都能设计
- **成长方向**：
  - 前期：高高在上的丹道宗师
  - 中期：与主角共同推动丹道标准化、分级化
  - 后期：丹府领袖 / 太上体系代表人物
- **高光方向**：
  - 不是只炼出最强丹药，而是推动“丹道如何服务整个文明”
  - 可在沈策、凡人寿命、人界医疗体系等问题上与主角形成极强戏剧张力
  - 他的加入意味着主角不再只是在打天下，而是在为天下建立真正的生命保障系统
