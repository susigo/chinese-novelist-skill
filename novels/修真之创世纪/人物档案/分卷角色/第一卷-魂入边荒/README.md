# 第一卷《魂入边荒》分卷角色索引

本目录存放只在第一卷承担主要叙事功能、后续未必长期保留主舞台位置的临时角色与卷内角色。

本 README 既是分卷角色目录样板，也是后续角色迁移时的说明入口：若某个卷内角色成长为长期核心角色，应将正文迁入对应长期类别目录，并只在这里保留迁移说明。

## 已建立角色
- `杜横山.md`
  - 代表：黑巷暴力秩序、贴脸追杀与生存压迫
- `邢魁.md`
  - 代表：矿场耗材逻辑、资源盘剥与灭口链条
- `马会泉.md`
  - 代表：黑市定价权、灰色中转秩序与利益折价逻辑
- `祁连鹤.md`
  - 代表：宗门外围现状秩序、合法收网与边荒治理机器
- `周石牛.md`
  - 代表：底层矿修样本、主角早期群众基础缩影
- `孟瘸子.md`
  - 代表：残器巷旧匠人视角、底层技术圈见证者

## 使用原则
- 分卷角色优先服务当前卷的冲突、氛围和结构推进。
- 卷内临时角色的主归属优先放在对应分卷目录，不与长期目录重复保留正文。
- 若后续成长为长期核心角色，再迁入对应长期类别目录。
- 迁移后本目录 README 只保留迁移说明，不保留第二份正文。
- 若主要作用结束，可继续保留在分卷目录，作为阶段人物档案存档。
