# 马会泉

- **年龄/职业**：初登场三十八岁左右；夜灯鬼市鉴宝主事，兼任黑货估价人与拍卖撮合人
- **外貌特征**：面白无须，常着干净得过分的黑衣，手指修长，眼神总像在衡量一件货值多少钱
- **性格核心**：精明、圆滑、极擅权衡，表面客气温和，骨子里一切都能拿来折价
- **核心价值观**：东西没有善恶，只有价差；人也一样
- **最大恐惧**：自己多年经营的“中立”身份被打破，沦为各方先杀的那一个
- **致命缺陷**：太相信自己能永远站在局外操盘，低估局势真正失控时“价钱”会失去意义
- **内心渴望**：想把夜灯鬼市从边荒黑市经营成谁都绕不开的灰色中转站
- **背景故事**：早年做过走货书手、票号账房、拍卖行学徒，后来转入鬼市，靠极高的眼力和极低的道德负担成了夜灯鬼市的鉴宝主事。他不亲手杀人，却比许多杀人的人更懂怎么把一个人连同秘密一起卖出最高价。最初注意到林渊，是因为他从未见过有人能把一堆废器修出“体系感”。
- **MBTI**：ENTP
- **人物定位**：卷一摇摆型反派 / 黑市秩序与利益逻辑代表
- **人物功能**：
  - 让黑市不只是混乱，而是“有秩序的黑”
  - 体现卷一经济线与情报线的灰色一面
  - 作为多方竞价、坐地估值、倒向赢家的典型操盘者
- **与主角关系演变**：
  1. 起初把林渊当成值得观察的“新货”
  2. 试图通过出价、试探和局势逼迫，把林渊、古纹与测灵盘一起包装成商品
  3. 最终因低估林渊而在夜市杀局中失去主动
- **成长方向**：
  - 卷一中后期的摇摆危险人物
  - 后续可视需要转为逃亡者、二手情报源或旧账线人物
- **高光方向**：
  - 一开口就要让人感觉：这人不动刀，也能比拿刀的人更可怕
  - 代表“有些秩序不靠法，而靠所有人默认把一切都折成价”
