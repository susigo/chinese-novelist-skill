# 第八卷：百道学宫（卷纲）

1. 这一卷要干什么：把第六卷带出的火种和第七卷重构后的新框架，带进学宫这种高阶资源与高阶人才汇聚地，抢实验条件、项目资源、弟子、名额和未来布局权。
2. 林渊赢了什么：赢得学宫中的资源入口、实验场、第一批真正接火的核心追随者，也赢得把自身体系从小团队绝活推进成可扩张势力底盘的关键站位。
3. 林渊失去了什么：失去了把技术藏在少数核心团队里的安全感。只要进入学宫，这条路就必须经受复现、争夺、抄袭、围堵与政治化。
4. 方法推进到哪一层：从异域重构成功，推进到可被公开复现、批量训练、规模扩张的文明框架。
5. 关键人物关系变化：宁观玄、裴知微、段长晏、韩行简等人以完整人格入局，分别从古法、丹道、空间网络、规则约束等方向形成高质量对照与合作；姬清微继续作为更高阶竞合与秩序对照角色发挥作用。
6. 给下卷留下什么更大的矛盾：一旦在学宫站稳，下一步就不再只是抢人才和资源，而是要直接接入真正的门路、节点与跨域流通，把框架落到现实基础设施上。
