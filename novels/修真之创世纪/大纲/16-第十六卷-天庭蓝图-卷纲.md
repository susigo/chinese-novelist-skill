# 第十六卷：天庭蓝图（卷纲）

1. 这一卷要干什么：把“新秩序”从一句口号，真正推成可落地、可守住、也会被天下群雄围攻的新天庭雏形。
2. 林渊赢了什么：赢得提出一套能够统摄星门、星舟、星符、工坊、兵马与诸域强者的新法度的资格，也赢得和天下诸方正面争天下的主动。
3. 林渊失去了什么：失去了继续含糊其辞的余地。从这一卷开始，所有人都能直接冲着他的新天庭开刀：你立的新法度会不会变成新的独尊？你要护众生，凭什么让诸强低头？你说兼容万道，究竟是真容得下，还是换一种更狠的压服？
4. 方法推进到哪一层：从立盟之法，推进到足以镇住诸天、分定上下、裁断名分的新天庭法度雏形。
5. 关键人物关系变化：姬清微、沈策留下的影响、以及其他核心同伴，都会从秩序、代价、实战、众生承受力等不同角度校验林渊；他们不再只是追随者，而是新天庭能否站住的试金石。
6. 给下卷留下什么更大的矛盾：若这套新法度不能真正让万道共存、让诸方看到活路，它就仍只是另一种霸权雏形；下一步，林渊必须把眼前这盘局真正压住，让更多人不得不跟着他往前走。
