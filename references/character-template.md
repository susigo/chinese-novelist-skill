# 人物档案总索引模板

`01-人物档案.md` 不再承担“所有角色正文全集”的职责，而是作为整部小说的人物档案总入口、目录索引和维护规则说明。

详细角色正文应写入 `novels/<小说名>/人物档案/` 目录树中的独立文件。

## 目录结构规范

### 长期角色目录

以下目录用于存放长期核心角色：

- `人物档案/主角/`
- `人物档案/核心配角/`
- `人物档案/反派与镜像/`
- `人物档案/专业支柱/`
- `人物档案/创业班底/`
- `人物档案/历史人物/`
- `人物档案/阵营预留/`

### 分卷角色目录

卷内临时角色统一放入：

- `人物档案/分卷角色/第X卷-卷名/`

建议在每个分卷目录下额外创建一个 `README.md`，用于记录本卷角色定位、使用原则和迁移说明。

## 维护规则

- 长期核心角色优先放入对应长期类别目录。
- 卷内临时角色优先放入对应分卷目录。
- 任一角色在任一时刻只保留一个主归属目录，不保留两份正文副本。
- 若卷内角色后续成长为长期核心角色，可迁入长期目录；原分卷 README 只保留迁移说明，不保留第二份正文。
- `01-人物档案.md` 负责告诉后续创作“角色现在放在哪里、为什么放在那里、最近是否发生过迁移”。

## `01-人物档案.md` 模板

```md

- 写新章节前，先看本文件确认当前卷相关角色的主归属目录，再读取对应角色文件。

## 迁移说明
- `[角色名]`：原位于 `人物档案/分卷角色/第一卷-[卷名]/`，现主归属迁入 `人物档案/核心配角/[角色名].md`
- 分卷目录不再保留该角色第二份正文，后续以新主归属目录为准。

## 维护原则
- 长期核心角色优先放长期目录。
- 卷内临时角色优先放分卷目录。
- 任一角色只保留一个主归属目录。
- 分卷角色升级为长期核心角色后，执行迁移并补充迁移说明。
```

## 角色单文件字段模板

每个详细角色文件建议保持独立文件、一角一档。可使用如下字段：

```md
# [角色名]

- **年龄/职业**：
- **外貌特征**：
- **性格核心**：
- **核心价值观**：
- **最大恐惧**：
- **致命缺陷**：
- **内心渴望**：
- **背景故事**：
- **MBTI**：
- **人物定位**：
- **人物功能**：
  -
- **与主角关系演变**：
  1.
- **成长方向**：
  -
- **高光方向**：
  -
```

## 字段说明

- `人物定位`：一句话说明该角色在整部小说或当前卷中的核心定位。
- `人物功能`：列出此角色承担的叙事功能，例如制造压力、提供专业支撑、承担情感线、承接制度冲突等。
- `与主角关系演变`：简述角色与主角关系如何推进、反转或破裂。
- `成长方向`：用于记录角色后续可能的升级、转化、退场或阵营变化。
- `高光方向`：提醒后续章节写作时，这个角色最适合以什么方式制造记忆点。

## 预留角色建议

对于 `阵营预留/` 中尚未完全定稿的角色，可以先使用简化版占位文件，只保留角色定位、未来用途和待补字段；一旦进入正式剧情，再补全完整字段。
